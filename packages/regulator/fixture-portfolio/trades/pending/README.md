A JSON file here is a trade list the household has agreed to execute: the date it was
planned on, and every trade with its ticker, side, shares and, for a sell, the lots it
comes from. Writing one is a commitment, so a unit asks for consent first — one question
naming every trade, its lots and the tax it realises — and writes nothing without a yes.
The person executes the list at the custodian and records the fills under `../executed/`.
