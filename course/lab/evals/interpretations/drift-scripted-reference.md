Scripted units, not a model: every number here is the harness grading a unit that does each task the way the contract asks, under the control arm (the loop with the test suite as its only check), the treatment arm (identity seeded; the identity-untouched, export-signature and glossary-lint checks; memory) and the four ablation arms, each the treatment minus one check. Read it as the graders' baseline, not as evidence that regulation helps. Every arm closes all six tasks in every repetition, with zero on every drift metric; the arms with the memory tool record one fact per repetition where the control arm has nowhere to put one. The one difference the treatment costs is wall-clock: the extra closeout checks (a probe process per signature expectation, a git diff per protected prefix, two git commands for the glossary, two staged runs of the inherited suite, and the post-merge run of the suite on the base) add tenths of a second per unit. There is no row where a gated arm loses on a well-behaved unit, and that is the point of running it: a check that refuses a correct unit — a glossary word in an honest comment, a signature probe that cannot load the module — would show here first. n is six tasks times three repetitions per arm; the six tasks of one repetition are not independent trials, so the intervals are narrower than the evidence warrants.
