Scripted units, not a model: every number here is the harness grading a unit that does each task the way the contract asks, under the control arm (the loop with the test suite as its only check) and the treatment arm (identity seeded, the identity-untouched and export-signature checks, memory). Read it as the graders' baseline, not as evidence that regulation helps. Both arms close all six tasks in every repetition, with zero on every drift metric; the treatment arm records one memory fact per repetition where the control arm has nowhere to put one. The one difference the treatment costs is wall-clock: the extra closeout checks (a probe process per signature expectation, a git diff per protected prefix) add milliseconds per unit. There is no row where the gated arm loses on a well-behaved unit, and that is the point of running it: a gate that refuses a correct unit would show here first. n is six tasks times three repetitions per arm; the six tasks of one repetition are not independent trials, so the intervals are narrower than the evidence warrants.
